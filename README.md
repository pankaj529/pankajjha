# Pankaj Jha — Android Developer Portfolio

A responsive, dark premium, single-page portfolio built with plain HTML, CSS, and JavaScript. No build tools or framework required.

## Preview locally
1. Extract the ZIP (if using the archive).
2. Open `index.html` in a modern browser.

## Before publishing, edit these placeholders in `index.html`
- `YOUR_EMAIL@example.com` — replace with the professional email you want public.
- `YOUR_GITHUB_URL` — replace with your GitHub profile URL.
- `assets/Pankaj-Jha-Resume.pdf` — add your resume PDF at that path, or change/remove the link.
- Replace the four project placeholders with accurate, public-safe summaries and real links.
- Add exact employer names, dates, and verified achievements only if you're comfortable publishing them.

## Free hosting
### Cloudflare Pages (quick option)
1. Create a GitHub repository and upload `index.html`, `README.md`, and the `assets` folder if you add a resume.
2. In Cloudflare, open Workers & Pages → Create → Pages → Connect to Git.
3. Select the repository. Since this is a static site, leave the build command blank and set the output directory to `/` (or follow the current Cloudflare Pages instructions).
4. Deploy. Cloudflare will provide a `*.pages.dev` URL.

GitHub Pages is another free static-hosting option. You can connect a custom domain later, after you register one.
